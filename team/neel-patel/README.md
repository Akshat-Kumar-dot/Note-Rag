## About the project

Notes RAG lets you ask questions about your own notes and get answers that
come only from them, with every claim cited back to the exact file and page.
See the main [README](../../README.md) for features and setup, and
[ARCHITECTURE.md](../../ARCHITECTURE.md) for the design choices.
